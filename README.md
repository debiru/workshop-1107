# PhoenixField

入力中のテキストを自動保存し、ブラウザのクラッシュやセッションタイムアウトで消えてしまった入力を復元する Chrome 拡張機能（Manifest V3）です。

## 使い方

1. テキスト系のフォーム（`<textarea>`、`<input type="text">`、`type="email"` など。`type="password"` は対象外）に入力すると、内容が自動で保存されます。
2. ページ下部に表示される「PhoenixField」バーを開きます（details 式に開閉します）。
3. バーの中で、保存データ（復元したい世代も選択）と、入力先のフォームコントロールを選び、「対応を追加」します。
4. 「自動入力を実行」ボタンを押すと、対応付けした内容が各フォームにセットされます。

保存データとフォームコントロールは、要素の `name` などでは自動的に結び付けません。保存先のページの HTML が変わっても、保存データの一覧から手動で対応付けて復元できます。

## データの保存について

- 保存先はブラウザ内（`chrome.storage.local`）のみで、外部に送信することはありません。
- データはページ（URL）ごとに管理します。URL のハッシュフラグメント（`#` 以降）は無視し、クエリパラメータは区別に含めます。
- バーの表示範囲は「このページ／同じパスでクエリ違い／同じドメイン内／すべて」に切り替えでき、別のページとして保存されたデータも呼び出せます。
- 入力のたびに最新版を保存し、一定間隔と変化量を満たした場合（初期値：3分＋10文字以上の変化）、または内容が急に減った場合に、過去の内容を「世代」として残します。世代は初期値で最大30件（設定で最大100件まで変更可能）、90日を過ぎた世代は自動削除します。ストレージ使用量が上限の約8割を超えた場合は、最新版を残して古い世代から自動削除します。
- 不要なデータは、バー内または設定画面から手動で削除できます。

## 設定画面

拡張機能の管理画面（`chrome://extensions` → PhoenixField →「拡張機能のオプション」）から、以下を変更できます。

- 自動保存の ON / OFF
- 対象範囲（テキスト系＋textarea ／ text と textarea のみ）
- 世代の最大保持数、スナップショットの間隔と変化量、世代の保持日数
- 保存データの一覧表示、ページ単位・全体の削除、JSON 形式でのエクスポート
- ストレージ使用量の確認

## permissions について

- `storage`：入力内容と設定をブラウザ内に保存するために必要です。これ以外の permission は要求しません。
- 全 http / https ページへの content script：各ページのフォームを検出して自動保存とツールバーを提供するために必要です。パスワード欄は読み取り対象から除外しています。

## Chrome での確認手順

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダを選ぶ
4. 任意の Web ページでテキストフォームに入力し、下部の PhoenixField バーに保存データが現れること、対応付けと自動入力で復元できることを確認する
