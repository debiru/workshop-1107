# Chrome ウェブストア向け紹介文

## 名称

PhoenixField

## 概要（短い説明）

入力中のテキストを自動保存し、ブラウザのクラッシュやセッションタイムアウトで消えてしまった入力を復元します。

## 詳細説明

PhoenixField は、Web ページのフォームに入力したテキストを自動で保存し、万が一のときに復元できる Chrome 拡張機能です。

長文のお問い合わせや申請フォームを入力している途中で、ブラウザがクラッシュしたり、サイト側でセッションが切れたりして、入力内容がすべて消えてしまったことはありませんか。PhoenixField は入力内容をブラウザ内に自動保存しておくことで、そうした事故から入力を守ります。

特徴

- テキスト入力（textarea とテキスト系の input）を自動保存。パスワード欄は対象外です
- 過去の内容も「世代」として保持。誤って全文を消してしまっても、直前の内容に戻せます
- 復元はページ内のツールバーから。保存データと入力欄を自分で対応付けて実行するので、ページの作りが変わっても保存データを使えます
- データはお使いのブラウザ内にのみ保存され、外部に送信されることはありません

仕事効率化
